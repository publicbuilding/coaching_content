# BookTuber Content Strategy: Fantasy & Sci-Fi Reviews

## Editorial Direction
**Tone:** Analytical, appreciative, engaging—like established BookTubers (OwlCrate, Merlin Books, etc.)  
**Format:** 8-15 minute video scripts  
**Depth:** Plot, themes, character development, worldbuilding, pacing, writing style  
**Angle:** Why these books matter + who should read them + specific scenes that define the story

## SCRIPT TEMPLATE

Each script follows this structure:
1. **Hook** (10-15 sec): Why this book is remarkable
2. **What It's About** (1-2 min): Plot + worldbuilding
3. **Why It Matters** (2-3 min): Themes + cultural impact
4. **The Good** (1-2 min): Standout elements
5. **The Critique** (1 min): Fair criticisms
6. **Who Should Read** (30 sec): Target audience
7. **Rating/Rec** (15 sec): Final thoughts + call-to-action

**Target Length:** 8-12 minutes per script  
**Tone:** Conversational, analytical, enthusiastic  
**Includes:** Key quotes, character highlights, thematic analysis
