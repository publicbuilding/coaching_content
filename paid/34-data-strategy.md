## The Data Stack

1. **Collection:** Get data from all sources (product, sales, support, finance)
2. **Storage:** Central data warehouse (database for analysis)
3. **Analysis:** Tools to query and analyze (SQL, Python, BI tools)
4. **Visualization:** Dashboards for decision-makers
5. **Action:** Make decisions based on data

---

## Key Metrics to Track

**Product:**
- DAU, MAU, session length
- Feature adoption
- Churn

**Sales:**
- Pipeline value
- Win rate
- CAC

**Finance:**
- Revenue
- Margin
- Burn rate

---

## Common Data Mistakes

1. **Too many metrics:** Focus on 10-15, not 100
2. **No action on data:** Measure but don't act
3. **Vanity metrics:** Track what looks good, not what matters
