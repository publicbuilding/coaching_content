## ⚠️ GOTCHAS & TIPS

### Before You Start
- ✅ Check licenses (CC0 vs CC-BY) - all free platforms allow commercial use
- ✅ Verify resolution consistency (mix 16x16 with 32x32 = visual chaos)
- ✅ Test Fiverr artist with single small commission first
- ✅ Download ALL free assets ASAP (licensing can change)

### Common Mistakes
- ❌ Mixing pixel densities (16x16 with 64x64)
- ❌ Ignoring isometric perspective consistency
- ❌ Not checking Fiverr artist portfolio before commission
- ❌ Forgetting about animation frame consistency
- ❌ Using paid Fiverr without testing free alternatives first

### Success Checklist
- [ ] All sprites 32x32 or 64x64 (not mixed)
- [ ] All isometric at same angle (45°)
- [ ] Color palette has 60 colors or less
- [ ] All assets have transparency/alpha channel
- [ ] Sprite sheets properly formatted for game engine
- [ ] Licenses documented for each asset pack
- [ ] Test build runs without visual artifacts
