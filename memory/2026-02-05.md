## Final Specifications

### Page Setup
- **Size**: A4
- **Margins**: 0.4in top/bottom, 2in left/right
- **DPI**: 300 (print-ready)
- **Orientation**: Portrait

### Typography & Styling
- **H1**: 26pt, navy (#1B3A6B), full-width navy background
- **H2**: 18pt, navy, full-width navy background, page-break-before: always
- **H2 (Case Studies)**: 22pt, navy, forces new page
- **H3**: 14pt, navy, light gold background
- **Company Profile**: 12pt, light gray (#999), subordinate to H2
- **Body text**: 11pt, line-height 1.7, margin-bottom 0.15in
- **List items**: 11pt, margin-bottom 0.08in

### Color Scheme
- **Primary**: #1B3A6B (navy blue)
- **Accent**: #D4A574 (gold)
- **Text**: #2C3E50 (dark slate)
- **Light backgrounds**: #F8F9FA, #FFF9F0
- **Metric boxes (yellow)**: #FFF3CD background

### Key Visual Elements
- **Cover page**: Full-bleed navy gradient (#1B3A6B → #0F1D41), white text, gold accent
- **Leverage Quadrant**: 2x2 matrix with color-coded quadrants (green/yellow/gray/red), row/column headers
- **Org chart**: Visual boxes with navy CEO, subordinate roles in lighter boxes
- **Section breaks**: Navy h2 headers act as page breaks with visual hierarchy
- **Metric boxes**: Yellow backgrounds with left border, 0.4in margins
- **Callout boxes**: Gold/beige backgrounds with colored left borders
- **Timeline sections**: Light gray background with navy left border

## Key Learnings
- **Margins matter**: Proper page margins (0.4in top/bottom, 2in sides) create professional appearance
- **Visual hierarchy**: Company Profile as sub-heading (12pt gray) reads better than equal h2
- **Color psychology**: Navy + gold is premium; yellow for metrics creates visual scannability
- **Page breaks**: Strategic breaks (h2 pages, case studies section) guide reader through content
- **Spacing optimization**: Tight paragraph margins (0.15in) allows more content while maintaining readability
