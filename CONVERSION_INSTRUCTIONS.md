## How to Convert

### Option A: Browser Print-to-PDF (Simplest)
```
1. Open each HTML file in Chrome/Firefox
2. Ctrl+P (or Cmd+P on Mac)
3. "Save as PDF"
4. Name: "01-high-performance-teams.pdf"
```

### Option B: Online Converter (Free)
```
1. Go to cloudconvert.com (free)
2. Upload HTML file
3. Select "PDF" as output
4. Download
5. Repeat for each file
```

### Option C: Terminal Command (If pandoc available)
```
pandoc input.html -o output.pdf
```
