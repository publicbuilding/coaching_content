## 2. VISUAL IDENTITY SYSTEM

### Logo Usage Rules

#### Logo Lockup (Horizontal)
```
[Logo Mark] [Wordmark Text]
    ↓
Used when space permits. Minimum width: 200px
Preferred for headers, hero sections, document titles
```

#### Logo Stacked (Vertical)
```
   [Logo Mark]
   [Wordmark]
Used in narrow spaces (sidebars, vertical layouts)
Minimum width: 120px
```

#### Logo Mark Only
```
[Geometric Symbol]
Used as favicon, avatar, app icon
Must be minimum 64px at display size
```

#### Clear Space
- **All Options:** Minimum clear space = 0.5x logo height on all sides
- Never crop, squeeze, or distort the logo
- Never rotate the logo except at 90° increments (rarely used)
- Never add effects (shadows, glows, rotations) unless in master design system

#### Minimum Sizes
- Digital display: 120px width
- Print: 1 inch (2.54cm) width
- Favicon: 64px at 1x display

### Color Mode Variations

#### Full Color (Primary)
- Use all brand colors as specified in your selected option
- Preferred across all applications

#### Monochrome (Black)
- Used when full color unavailable
- Logo in solid black (#000000)
- Acceptable for faxes, legal documents, restricted printing

#### Monochrome (White)
- Used on dark/colored backgrounds
- Logo in solid white (#FFFFFF)
- Maintains logo structure, not knockout effect

#### Reverse/Knockout
- White logo on dark colored background
- Used in hero sections, dark cards, overlay text
- Ensure sufficient contrast

**Never use:**
- Outlined versions
- Gradients or effects
- Different colors than specified palette
- Logo text in different font

## 3. COLOR SYSTEM

### Primary Palette Usage

The three brand identity options (A, B, C) each have defined color palettes. Select ONE option for organizational consistency.

#### Option A: Premium/Conservative
- Use when positioning as heritage, trusted, exclusive
- Typical: Financial services, law firms, luxury brands
- Emotional tone: Sophisticated, timeless

#### Option B: Modern/Bold
- Use when positioning as innovative, energetic, progressive
- Typical: Technology, startups, dynamic companies
- Emotional tone: Forward-thinking, confident

#### Option C: Minimalist
- Use when positioning as focused, refined, essential
- Typical: Consulting, minimalist brands, clarity-focused
- Emotional tone: Intentional, clear, precise

### Color Application Rules

#### Dominant Color (60%)
- Primary background color or largest visual element
- Sets overall tone and mood

#### Secondary Color (25%)
- Supporting structures, secondary elements
- Provides depth and hierarchy

#### Accent Color (15%)
- Buttons, highlights, key messages
- Draws attention to critical elements

### Contrast & Accessibility

- All text combinations must meet WCAG AA standards minimum (4.5:1 ratio)
- AAA compliance (7:1 ratio) preferred for body text
- Test all color combinations for color-blind accessibility
- Use tools: contrast checkers, color-blind simulators

### Color Dos & Don'ts

✅ **DO:**
- Use colors as specified in hex codes
- Test on multiple screens (monitor calibration varies)
- Use accent colors sparingly for impact
- Create sufficient contrast for readability

❌ **DON'T:**
- Invent new colors from the palette
- Oversaturate colors (they're already balanced)
- Use accent color for large background areas
- Forget accessibility when combining colors

## 4. TYPOGRAPHY SYSTEM

### Font Pairing Strategy

**Primary Font (Headlines):**
- Creates brand personality
- Conveys tone (luxury, modern, minimal)
- Used sparingly for maximum impact

**Secondary Font (Body):**
- Optimized for readability
- Used for all continuous text
- Must work at small sizes (12px minimum)

**Accent Font (Optional):**
- Technical or special emphasis
- Limited use
- Never for body text

### Type Hierarchy & Sizing

#### Desktop
```
H1: 48px | Weight: Bold | Line height: 1.2
H2: 36px | Weight: Bold | Line height: 1.3
H3: 24px | Weight: SemiBold | Line height: 1.4
H4: 18px | Weight: SemiBold | Line height: 1.5
Body: 16px | Weight: Regular | Line height: 1.6
Small: 13px | Weight: Regular | Line height: 1.5
Label: 12px | Weight: Medium | Line height: 1.4
```

#### Mobile
```
H1: 32px | Weight: Bold | Line height: 1.3
H2: 24px | Weight: Bold | Line height: 1.4
H3: 18px | Weight: SemiBold | Line height: 1.5
Body: 14px | Weight: Regular | Line height: 1.6
Small: 12px | Weight: Regular | Line height: 1.5
```

### Typography Rules

✅ **DO:**
- Use specified fonts only (no substitutions without approval)
- Scale type proportionally across devices
- Maintain line-height for readability (1.5x minimum for body)
- Limit to 2 weights per font family (regular + bold preferred)
- Limit paragraph line length to 70-75 characters

❌ **DON'T:**
- Use more than 2 font families
- Mix serif + sans-serif casually (only with intent)
- Set body text below 14px
- Set line-height below 1.5x for body text
- Use ALL CAPS for body paragraphs
- Justify text (left-align preferred)

### Font Pairing Reference

**Option A Pairing:** Georgia (headlines) + Helvetica Neue (body)
**Option B Pairing:** Montserrat (headlines) + Open Sans (body)
**Option C Pairing:** Helvetica Neue (headlines) + Segoe UI (body)

## 5. IMAGERY & VISUAL STYLE

### Photography Direction

#### Style
- Professional, high-quality (1200px+ width minimum)
- Natural lighting preferred (avoid harsh shadows)
- Composed & intentional (not candid snapshots)

#### Subject Matter
- People: Diverse, professional, relatable
- Settings: Clean, contemporary, relevant to message
- Objects: Relevant to industry/solution, not generic stock

#### Color Treatment
- Option A: Subtle deep red overlay (10-20% opacity)
- Option B: Bold red or gold overlay (15-25% opacity)
- Option C: B&W with single red accent OR full color with balanced palette

### Illustration Style

#### Option A (Premium)
- Detailed line work, geometric patterns
- Incorporate gold accents
- Formal, sophisticated

#### Option B (Modern)
- Bold geometric shapes, minimal line work
- Bright color blocks
- Dynamic, forward-motion implied

#### Option C (Minimalist)
- Simple line work, SVG-style
- High whitespace
- Functional, not decorative

### Icon Standards

- **Style:** Match selected brand option
- **Weight:** 2px stroke for best visibility
- **Sizing:** Scale at 16px, 24px, 32px, 48px, 64px multiples
- **Padding:** 2px internal padding around icons
- **Colors:** Dark gray primary, light gray secondary, red alerts

## 6. APPLICATIONS GUIDE

### Website & Digital

#### Header/Navigation
- Logo positioned top-left (or center if mobile)
- Primary color background OR white with bordered logo
- Navigation: Secondary font, 14-16px
- Call-to-action button in accent color

#### Hero Section
- Full-width or contained layout
- Background: Primary color OR hero image with overlay
- Headline: H1, primary font, 48px+ on desktop
- Subheading: H2 or body+, 20-24px
- CTA button: Accent color, prominent placement

#### Content Sections
- Alternating background colors (white + secondary)
- Generous whitespace: 60px margins (desktop)
- Headings: H2 or H3, 24-36px
- Body text: 16px, 1.6x line-height

#### Cards
- White or secondary color background
- Subtle shadow (0 2px 8px rgba(0,0,0,0.08))
- Padding: 24px minimum
- Border: Optional 1px light gray divider

#### Buttons

**Primary Button:**
- Background: Accent color (red/gold)
- Text: White, bold
- Padding: 12px 24px
- Border radius: 4-8px
- Hover: Darker shade of accent color
- Active: Subtle inset shadow

**Secondary Button:**
- Background: Transparent or secondary color light
- Text: Primary color or dark gray
- Border: 1px primary color
- Padding: 12px 24px
- Hover: Light background color

**Text Link:**
- Color: Accent color (red)
- Text decoration: Underline
- Hover: Darker red, possibly background highlight

### Print Materials

#### Business Card
- Size: 3.5" × 2" (standard)
- Layout: Logo + name + title + contact
- Colors: Full palette
- Paper: Premium cardstock (250-300 gsm)

#### Letterhead
- Logo: Top-left or center
- Page margins: 0.75" on all sides
- Footer: Company name, website, contact
- Colors: Logo + minimal accent line

#### Envelope
- Return address: Top-left, 8pt font
- Logo: Bottom-left or center-top, 0.5" size
- Colors: Full color recommended

#### Brochure/Pamphlet
- Cover: Bold hero image + H1 headline + CTA
- Interior: Mix of content + imagery
- Color section: Primary color page
- Back: Contact info, tagline, logo

### Presentations (PowerPoint/Google Slides)

- **Slide Master:** Include logo, footer, color backgrounds
- **Title Slide:** Hero image + company name + title + date
- **Content Slides:** Title + bullet points + space for images
- **Accent:** Primary color headers or accent bars
- **Fonts:** Use only specified fonts from typography system

### Email Templates

- **Header:** Logo + navigation links
- **Body:** Consistent spacing, readable font size (14-16px)
- **CTA:** Prominent button in accent color
- **Footer:** Contact info, social links, unsubscribe
- **Background:** White or very light secondary color

### Social Media

#### LinkedIn
- **Banner:** 1200 × 627px
- **Logo:** Top-left or center, 100-150px
- **Font:** Headline (36px) + body (16px)
- **Color:** Use primary or secondary with white text
- **CTA:** Accent color button

#### Twitter/X
- **Header:** 1500 × 500px
- **Profile:** Logo centered, 400 × 400px
- **Text:** Keep font large (18px+ for headlines)
- **Links:** Colored in accent red

#### Instagram
- **Format:** 1080 × 1080px (square)
- **Style:** Bold image + minimal text OR text-heavy graphic
- **Palette:** Use full color palette but keep readable

## 7. BRAND VOICE & TONE

### Voice Characteristics
- Professional, authoritative, knowledgeable
- Clear, concise, no jargon
- Confident, not arrogant
- Approachable, human
- Action-oriented

### Tone by Context

**Marketing/Sales:** Aspirational, confident, benefit-focused
**Support/Help:** Warm, empathetic, helpful
**Legal/Compliance:** Precise, formal, clear
**Internal/Culture:** Friendly, encouraging, inclusive

### Writing Guidelines

✅ **DO:**
- Use active voice
- Write in second person ("you") when addressing audience
- Use power words: Transform, Accelerate, Optimize, Empower
- Keep sentences short (average 15-20 words)
- Use numbers & specifics instead of vague claims

❌ **DON'T:**
- Use jargon without definition
- Write passive voice
- Use generic superlatives (amazing, awesome, incredible)
- Use ALL CAPS for emphasis (use bold instead)
- Exceed 3 levels of nested bullets

## 8. RESTRICTED USE & VIOLATIONS

### Logo Misuse Examples

❌ **Never:**
- Stretch or squeeze logo (distorts proportions)
- Rotate to arbitrary angles
- Apply filters or effects
- Use unauthorized colors
- Place on insufficient contrast background
- Resize without respecting minimum sizes

### Color Violations

❌ **Never:**
- Use colors outside the specified palette
- Create new color variations
- Use accent color for large backgrounds
- Apply transparency to change perceived color
- Oversaturate or desaturate colors

### Typography Violations

❌ **Never:**
- Use unauthorized fonts
- Mix 3+ font families
- Set body text below 14px
- Justify body text
- Use serif fonts for body in Option B/C
- Kern text casually (only for logo lockup)

### How to Request Exceptions

All brand guideline exceptions require:
1. Written request with business justification
2. Visual mockup of the exception
3. Approval from Brand Lead/CMO
4. Documentation in brand exception log
