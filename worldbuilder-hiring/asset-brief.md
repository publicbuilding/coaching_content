# WorldBuilder Asset Brief

## Project Overview
Game: **WorldBuilder** - A city-building/settlement simulation game with Asian-inspired art style
Budget: $1,000-$5,000 (full asset package)
Timeline: 4-8 weeks (phased delivery)
Ongoing work: Available for post-launch polish & DLC content

---

## Asset Categories & Specifications

### 1. **Character Sprites (Settlement Leaders & NPCs)**
- **Count:** 12-15 unique character sprites
- **Style:** Asian-inspired, anime/watercolor blend
- **Resolution:** 128x256px (idle), with walk/talk animation frames
- **Deliverables:**
  - Idle pose (front + 3/4 view)
  - Walk animation (4-6 frames)
  - Talk/gesture animation (3-4 frames)
  - Emotional expressions (happy, concerned, angry)
- **Examples:** Merchant, Scholar, Warrior, Elder, Farmer, Craftsperson
- **Budget:** $300-500 per 4-character set

### 2. **Building Icons & Structures**
- **Count:** 30-40 isometric building icons
- **Style:** Flat + isometric, hand-drawn with subtle procedural accents
- **Resolution:** 64x64px base, 128x128px for large buildings
- **Deliverables:**
  - Farm, Market, Barracks, Temple, Workshop, Library, Granary, etc.
  - Damaged/upgrade variants (+20% assets)
  - Icon versions for UI (32x32px)
- **Budget:** $400-600 per set of 20 buildings

### 3. **Terrain & Vegetation**
- **Count:** 40-50 assets
- **Style:** Procedural base + hand-drawn overlay blend
- **Deliverables:**
  - Terrain types: Grass, Mountain, Water, Desert, Forest floor
  - Trees (3-4 variants, idle + seasonal states)
  - Rocks, bushes, flowers, fallen logs
  - Water tiles (animated ripples)
- **Budget:** $300-400 for tileset + 20 vegetation assets

### 4. **UI Elements**
- **Count:** 50-70 components
- **Style:** Consistent with Asian aesthetic (clean, elegant borders)
- **Deliverables:**
  - Buttons (default, hover, pressed, disabled states)
  - Panels and backgrounds
  - Resource icons (food, wood, gold, stone, population)
  - Status indicators (progress bars, health, happiness)
  - Menu layouts (pause, settings, inventory)
- **Budget:** $200-300 for complete UI kit

### 5. **Animated Effects**
- **Count:** 15-20 animations
- **Resolution:** 64x64px to 256x256px (varies)
- **Deliverables:**
  - Resource gathering (woodcutting, farming animation)
  - Construction (building placement, crane lift)
  - Disaster effects (fire, flood, earthquake)
  - Celebration/event particles (fireworks, blessings)
  - Environmental (wind through trees, water flow)
- **Format:** Sprite sheets + individual frames
- **Budget:** $300-400 for animation package

---

## Technical Requirements

### File Formats
- **Primary:** PNG (transparent background, 32-bit)
- **Animated:** Sprite sheets (JSON metadata or standard naming)
- **Alternative:** PSD/Aseprite source files for future modifications

### Color Palette
- Base: Warm earth tones (terracotta, sage, gold accents)
- Consistent with existing procedural assets (gradual replacement planned)

### Style Guide
- Asian-inspired (East/Southeast Asia preferred)
- Hand-drawn aesthetic with clean lines
- Blend of flat design + subtle depth
- Resolution independence (assets scale cleanly)
