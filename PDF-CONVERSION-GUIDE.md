## How to Convert (Choose ONE method)

### METHOD 1: cloudconvert.com (FASTEST — 2 minutes) ⭐ RECOMMENDED

```
1. Open https://cloudconvert.com in browser
2. Click "Select Files" or drag HTML file
3. Select "HTML" as input format (auto-detects)
4. Select "PDF" as output format
5. Click "Convert"
6. Download the PDF
7. Repeat steps 2-6 for each of the 5 files
8. Total time: ~2 minutes for all 5
```

**Result:** 5 PDFs ready to upload to Gumroad

---

### METHOD 2: Browser Print-to-PDF (SIMPLEST — 5 minutes)

```
1. Open HTML file in Chrome or Firefox
2. Right-click → Print (or Ctrl+P / Cmd+P)
3. Select "Save as PDF"
4. Give it a simple name: "01-high-performance-teams.pdf"
5. Click "Save"
6. Repeat for each HTML file
7. Total time: ~1 minute per file × 5 = 5 minutes
```

**Pros:**
- No website signup needed
- No external dependencies
- Full control over output

**Cons:**
- Slightly slower
- More manual steps

---

### METHOD 3: Command Line (If you have tools)

```bash
# If wkhtmltopdf installed:
wkhtmltopdf input.html output.pdf

# If pandoc installed:
pandoc input.html -o output.pdf
```

Or run the provided script:
