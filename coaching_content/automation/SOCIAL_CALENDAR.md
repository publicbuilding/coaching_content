## Response & Engagement Strategy

### Real-Time Engagement (First 2 Hours)
- **Monitor** first 2 hours after posting
- **Respond** to every comment
- **Ask follow-ups** to encourage more comments
- **Retweet** top replies with kind commentary

### Daily Review (30 min)
- Check each platform's notifications
- Answer questions in depth
- Build relationships with engaged followers
- Note patterns in questions (content ideas!)

### Weekly Analytics Review
- Pull performance data from Buffer/Later
- Identify top 5 posts of the week
- Note which topics, angles, times performed best
- Plan next week around winners

## Content Repurposing Rules

✅ **DO:**
- Reuse high-performing content 3-4 weeks later
- Adapt same script for different platforms
- Build on successful posts with follow-ups
- Create "part 2" posts that reference viral hits
- Use top posts as newsletter content

❌ **DON'T:**
- Post identical content twice in same month
- Use same image without variation
- Post top content on multiple platforms simultaneously (same day)
- Ignore audience feedback
- Keep posting low-performing content (< 1% engagement after 2 attempts)
