## Quick Entry Tips

**If using Google Sheets:**
1. Copy the daily entry form above
2. Open Tab 1: "Daily Revenue Log"
3. Create a new row for each day
4. Fill only the fields with data (leave others blank)
5. Formulas in Tab 2 will auto-calculate summaries

**Speed Entry (Minimal Data):**
If you're short on time, at minimum log:
- Date
- Total daily revenue (all sources)
- Email list size
- Any major news/notes

**Full Entry (Complete Data):**
For better analytics, log everything:
- Breaks revenue down by source
- Customer counts per source
- All social metrics
- Traffic & conversion data

**When to Log:**
- **Best time:** End of day (before bed)
- **Frequency:** Daily (or batch 2-3 days at once)
- **Time needed:** 5-10 minutes per day

| Metric | Where to Find |
|--------|--------------|
| Gumroad Revenue | Gumroad → Dashboard → Earnings |
| Gumroad Customers | Gumroad → Customers tab |
| Gumroad Followers | Gumroad → Store profile |
| Substack Revenue | Substack → Analytics → Revenue |
| Substack Subscribers | Substack → Subscribers page |
| Email List Size | Email provider (ConvertKit, Substack, etc.) |
| Twitter Followers | Twitter profile page |
| LinkedIn Followers | LinkedIn profile page |
| Social Clicks | UTM parameters in Google Analytics or link tracking |
| Ad Spend | Facebook Ads, Google Ads, or email receipt |

## Automation Tips

**To reduce manual entry:**

1. **Use Google Forms** — Create a simple form that logs directly to your sheet
2. **IFTTT/Zapier** — Auto-log follower counts from social media
3. **Google Analytics integration** — Automatically pull traffic data
4. **Gumroad API** — Pull sales data directly (if available)
5. **Substack integration** — Use email receipts or API to auto-log

**For now:** Manual daily entry is fine. Start with that. Automate later as you grow.

---

## Data Privacy & Retention

- **Keep daily logs for:** At least 12 months
- **Archive monthly:** Move old data to a "Historical" tab
- **Backup:** Export CSV monthly to external storage
- **Sharing:** Never share raw customer emails/personal data
- **Public dashboards:** Okay to share anonymized metrics (total revenue, subscriber counts, conversion rates)
