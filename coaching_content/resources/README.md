## 🎯 Template Best Practices

### For PowerPoint
- Start with our branded template
- Keep design consistent
- Use approved color palette
- Follow typography guidelines
- Test on projector before presenting

### For Excel
- Use provided templates as base
- Maintain consistent formatting
- Include data labels and legends
- Save in xlsx format for compatibility
- Test calculations before distribution

### For Word
- Use branded header/footer
- Apply consistent styles
- Use approved fonts
- Maintain margins and spacing
- Export to PDF for distribution

## 🔄 Updating Resources

When resources need updating:

1. **Update branding materials**
   - Update logo in branding/ folder
   - Update color palette if brand changes
   - Update brand guidelines document
   - Notify team of changes

2. **Update templates**
   - Modify template files
   - Update version number if major changes
   - Test with sample content
   - Update this README.md

3. **Communicate changes**
   - Email team about updates
   - Add version dates to templates
   - Document what changed in README
   - Update git with descriptive commit

## 🔤 Typography Guidelines

**Headings:** Segoe UI, Roboto, or system sans-serif  
**Body Text:** Georgia or similar serif font  
**Code/Technical:** Monaco, Courier New, monospace  
**Font Sizes:**
- H1: 32px
- H2: 24px
- H3: 18px
- Body: 16px

## 📱 Responsive Design
