## 1. MASTER SLIDE LAYOUTS

### Master Slide Setup Structure

```
Executive Forge Master Slide
├── Title Slide Master
├── Content Slide Master
├── Two-Column Master
├── Three-Column Master
├── Section Header Master
├── Blank/Custom Master
└── Notes Page Master
```

### Layout Specifications

#### 1.1 Title Slide Master
```
┌────────────────────────────────────────────────────┐
│                                                    │
│                    [LOGO]                          │
│                                                    │
│            PRESENTATION TITLE                      │
│         [Subtitle/Author Information]              │
│                                                    │
│  [Date] | [Company Name] | [Your Name]            │
│                                                    │
└────────────────────────────────────────────────────┘
```

**Specifications:**
- **Background:** Primary color (full bleed)
- **Logo:** 1.5" width, top-left corner, 0.5" margins
- **Title:** H1 size (54pt), white text, bold, sans-serif
- **Subtitle:** H2 size (32pt), secondary color or light gray, regular weight
- **Footer:** 12pt, light gray text, right-aligned
- **Dimensions:** 10" × 7.5" (standard 4:3) or 10" × 5.625" (16:9)

#### 1.2 Content Slide Master
```
┌────────────────────────────────────────────────────┐
│  [LOGO] SLIDE TITLE                               │
├────────────────────────────────────────────────────┤
│                                                    │
│  • Bullet Point 1                                  │
│  • Bullet Point 2                                  │
│    - Sub-bullet                                    │
│  • Bullet Point 3                                  │
│                                                    │
│  [FOOTER: Page # | Date | Company]                │
└────────────────────────────────────────────────────┘
```

**Specifications:**
- **Background:** White or light secondary color
- **Header Area:** 0.5" height, primary color background
- **Logo:** 0.5" width, left-aligned, white color
- **Slide Title:** H2 size (40pt), dark gray/black, left-aligned, 0.75" from top
- **Content Area:** 7" × 5" (16:9), top margin 1.5"
- **Footer:** 10pt gray text, centered or right-aligned, 0.5" from bottom
- **Margins:** 0.75" left/right, 0.5" top/bottom

#### 1.3 Two-Column Master
```
┌────────────────────────────────────────────────────┐
│  SLIDE TITLE                                       │
├──────────────────────┬──────────────────────────────┤
│                      │                              │
│  [LEFT COLUMN]       │  [RIGHT COLUMN]              │
│                      │                              │
│  • Point 1           │  • Point A                   │
│  • Point 2           │  • Point B                   │
│                      │                              │
│  [IMAGE/CHART]       │  [IMAGE/CHART]               │
│                      │                              │
└──────────────────────┴──────────────────────────────┘
```

**Specifications:**
- **Column Width:** 3.5" each with 0.5" gutter
- **Title Area:** Same as Content Slide
- **Column Headers:** 14pt, bold, dark gray (optional)
- **Content:** 12pt, regular weight, left-aligned
- **Divider:** 1px light gray line between columns

#### 1.4 Three-Column Master
```
┌────────────────────────────────────────────────────┐
│  SLIDE TITLE                                       │
├─────────────┬──────────────────┬─────────────────┤
│             │                  │                 │
│  COLUMN 1   │   COLUMN 2       │  COLUMN 3       │
│             │                  │                 │
│  • Point 1  │  • Point A       │  • Point X      │

│             │  • Point C       │                 │
│             │                  │                 │

```

**Specifications:**
- **Column Width:** 2.75" each with 0.3" gutters
- **Headers:** 13pt, bold, centered, primary accent color
- **Content:** 11pt, regular, left-aligned
- **Max 3 bullets per column for readability**

#### 1.5 Section Header Master
```
┌────────────────────────────────────────────────────┐
│                                                    │
│                    [ACCENT BAR]                    │
│                                                    │
│            SECTION NAME                            │
│         Supporting Headline (Optional)              │
│                                                    │
│            [ACCENT BAR]                            │
│                                                    │
└────────────────────────────────────────────────────┘
```

**Specifications:**
- **Background:** White with subtle gradient (5-10% darker toward bottom)
- **Accent Bars:** Primary color, 2" × 0.25", positioned top & bottom
- **Section Title:** H1 size (52pt), dark gray, bold, centered
- **Subtitle:** 24pt, secondary color, centered, italic (optional)

#### 1.6 Blank Master
- Completely blank slide (no headers, footers, placeholders)
- Used for custom layouts, full-page images, custom graphics
- Can add logo manually if desired

1. **Go to Design > Themes > Save Current Theme**
2. **Name it:** "Executive Forge [Option Letter]"
3. **Store in:** `Documents\Custom Office Templates`
4. **Share with team:** Distribute .thmx file

#### Steps to Create Custom Theme:

**In PowerPoint:**
1. Open blank presentation
2. Go to **Design > Design Ideas > Variants** (or customize)
3. Right-click any variant → **Edit Master**
4. Set up master slides (as described above)
5. Go to **Design > Variants > Colors > Customize Colors**
   - Set Theme Colors to match brand palette
   - Save as "Executive Forge [Option]"
6. Repeat for **Fonts > Customize Fonts**
7. Apply background colors to each master
8. **File > Save As > Save Current Theme** (as .thmx)

## 3. SLIDE-BY-SLIDE FORMATTING SPECIFICATIONS

### 3.1 Title Slide
```
Format: Title Slide Master
Content:
  - Company logo (1.5" × 1.5")
  - Presentation title (54pt, bold)
  - Subtitle or key message (32pt)
  - Author name, date, department
  - Contact information (footer, 10pt)

Colors:
  - Background: Primary color
  - Text: White
  - Accents: Gold (optional bars or decorative elements)

Image/Design:
  - Optional hero image (aligned right, 40% opacity background)
  - Geometric shape overlay (abstract, brand-aligned)
```

### 3.2 Agenda/Overview Slide
```
Format: Content Slide Master
Title: "Agenda" or "Today's Discussion"

Content Structure:
  - Numbered list (1-6 items)
  - One line each, max 10 words
  - Optional icons next to each item (12pt, brand color)

Color Coding:
  - Item titles: Bold, primary color
  - Optional visual indicators (small dots or bars)

Design:
  - Clean, scannable layout
  - Whitespace between items (0.15")
  - Optional: subtle horizontal dividers
```

### 3.3 Content Slide with Image
```
Format: Two-Column Master
Left Column (60%):
  - Heading (28pt, bold)
  - 3-4 bullet points
  - Bullet style: Small circles, primary color
  - Line spacing: 1.5x

Right Column (40%):
  - Hero image (high quality, 4" × 3" minimum)
  - Image caption (10pt, gray)
  - Optional brand color border (2px, primary)

Colors:
  - Background: White
  - Headings: Dark gray or primary color
  - Body text: Dark gray
```

### 3.4 Quote/Testimonial Slide
```
Format: Section Header Master (modified)

Central Content:
  - Quote text: 32pt, italic, dark gray
  - Quotation marks: Large, gold color, 10% opacity
  - Attribution: 14pt, bold, primary color
  - Source: 12pt, gray

Design:
  - Centered alignment
  - Generous whitespace (40% empty space)
  - Optional: subtle background pattern (5% opacity)
  - Optional: decorative element (brand shape)
```

### 3.5 Data/Statistics Slide
```
Format: Three-Column Master

Left Column:
  - Large number (72pt, bold, primary color)
  - Metric label (14pt, gray)
  - Supporting detail (11pt)

Center Column:
  - [Repeat left format]

Right Column:
  - [Repeat left format]

Design:
  - Icons above numbers (24pt, brand color)
  - Minimal text, maximum impact
  - Background: Optional light primary color tint (5% opacity)
```

### 3.6 Action/Call-to-Action Slide
```
Format: Blank Master (custom)

Content:
  - Heading: "Next Steps" or "[Action Item]"
  - 3-4 action items with ownership
  - Format: "ACTION | Owner | DueDate"

Design:
  - Primary color background (left 30%) | White (right 70%)
  - CTA button: Prominent, accent color, 0.5" × 2" minimum
  - Button text: Bold, white, 18pt

Example Layout:
  [Primary Color | ✓ Approve Proposal - John | Feb 5     ]
  [Primary Color | ✓ Kickoff Meeting - Sarah | Feb 8     ]
  [Primary Color | ✓ Finalize Scope - Team | Feb 10      ]

```
Format: Title Slide Master (modified)

Content:
  - "Thank You" (54pt, bold)
  - Optional: Key takeaway (28pt, gray)

    - Name: 16pt

## 4. CHART & GRAPH STYLING GUIDE

### Chart Color Palette (All Options)

**Primary Series:** Brand primary color
**Secondary Series:** Brand secondary color
**Tertiary Series:** Brand accent color
**Additional Series:** Grayscale or complementary colors (max 5 series total)

### Bar Chart Specifications

```
Bar Style:
  - Width: Proportional to space (avoid thin bars)
  - Color: Primary color (option 1), secondary (option 2), accent (comparison)
  - Border: 1px border, matching chart background color
  - Shadow: None (keep clean)

Axes:
  - Axis lines: 0.5pt, light gray
  - Labels: 11pt, dark gray, left-aligned
  - Values: 11pt, dark gray

Legend:
  - Position: Right side or below chart
  - Font: 10pt, regular weight
  - Background: Transparent or very light color

Labels:
  - Data labels: 10pt, show on bars OR in legend (not both)
  - Colors: Match bar colors
```

### Line Chart Specifications

```
Line Style:
  - Weight: 2pt minimum for clarity
  - Color: Brand palette colors
  - Points: Circle, 5pt diameter, filled with color
  - Point labels: Optional (10pt, above/below point)

Axes:
  - X-axis: Category labels (12pt)
  - Y-axis: Value labels (11pt)
  - Grid lines: Light gray, optional (0.5pt, dashed)
  - Axis lines: 1pt, dark gray

Fill:
  - Below line: Optional, 20% opacity of line color
  - Creates emphasis without overwhelming

Legend:
  - Top right or below chart
  - 10pt font, compact format
```

### Pie Chart Specifications

```
Slice Style:
  - Colors: Use 3-5 brand colors maximum
  - Borders: 1px white border between slices
  - Size: Minimum 3" diameter for readability

Labels:
  - Position: Outside pie, with leader lines
  - Format: "Label 25%" or percentage only
  - Font: 11pt, dark gray
  - Donut hole (optional): 40% diameter for modern look

Legend:
  - Below or to the right
  - Show percentages
  - Order by size (largest first)
```

### Table Specifications

```
Header Row:
  - Background: Brand primary color
  - Text: White, bold, 12pt
  - Padding: 8pt vertical, 10pt horizontal
  - Alignment: Left (text), Right (numbers)

Data Rows:
  - Background: Alternate white & very light gray (5% opacity)
  - Text: Dark gray, 11pt, regular
  - Borders: Light gray, 0.5pt
  - Padding: 8pt vertical, 10pt horizontal

Total Row (if applicable):
  - Background: Light primary color (10% opacity)
  - Text: Bold, dark gray
  - Border: 1pt dark gray above & below

Column Width:
  - Proportional to content length
  - No text wrapping (maximize readability)
  - Minimum 1" per column
```

### General Chart Design Rules

✅ **DO:**
- Use only brand colors (no default PowerPoint colors)
- Ensure data is the focus, not decoration
- Add grid lines for easier reading
- Include axis labels and units
- Make charts large (minimum 4" × 3")

❌ **DON'T:**
- Use 3D effects or drop shadows
- Add unnecessary data series
- Crowd multiple charts on one slide
- Use default chart colors
- Use chartjunk (excessive decoration)

### Chart Implementation in PowerPoint

1. Insert chart (Insert > Chart)
2. Edit data in Excel window
3. Right-click chart → "Format Chart Area"
4. Set colors manually or use theme colors
5. Adjust fonts in "Format Axis" dialog
6. Remove legend if too cluttered
7. Test print quality before final

## 7. PRESENTER NOTES & SPEAKER VIEW

### Presenter Notes Template

```
[SLIDE TITLE]

SPEAKER NOTES:
[Key points to emphasize]
[Related statistics or deeper context]
[Potential questions & answers]
[Talking points (30-45 seconds per slide)]

TIMING: [Target time for this slide]
TRANSITION: [How to transition to next slide]
```

### Example Presenter Notes Entry

```
EXECUTIVE SUMMARY
Slide 2: Situation / Context

SPEAKER NOTES:
Key Points:
  • Current market is facing 3x growth in demand
  • Legacy systems preventing us from scaling
  • Competitor launched similar solution last quarter

Deeper Context:
  • Our current platform can handle 100K users; demand is 500K
  • Team is currently split across 4 time zones with no unified tools
  • Market analysis shows 18-month window to maintain leadership

Potential Questions:
  Q: "What's the cost of delay?"
  A: "Each month of delay costs us ~$50K in lost contracts"

  Q: "Why not build internally?"
  A: "Timeline—internal team is at capacity; this gets us to market in 6 months vs. 12"

TALKING POINTS (45 seconds):
"As you can see, we're at a critical juncture. Demand for our solution has tripled
in the last 18 months, but our infrastructure isn't keeping up. We need to act now
to capture this opportunity before competitors do."

TIMING: 1:00 minute for this slide
TRANSITION: "Let's look at how we can address this..."
```

### Using Speaker View in PowerPoint

1. **One Display (Presenter):** Notes visible to you only
2. **Set up:**
   - **Slide Show > From Beginning**
   - Use **Presenter View** (secondary monitor shows notes + speaker timer)
   - Advance slides with mouse/keyboard (not visible to audience)

3. **Notes appear in:**
   - Speaker View (speaker monitor)
   - Print handouts (1 note per page)
   - Export as PDF with notes

## 8. IMPLEMENTATION INSTRUCTIONS

### Option 1: Using PowerPoint Templates (Built-in)

**Step 1: Download Theme File**
- Save `Executive Forge [Option].thmx` to `Documents\Custom Office Templates`

**Step 2: Create New Presentation**
- Open PowerPoint
- **File > New**
- Search "Executive Forge"
- Click template to create presentation

**Step 3: Customize**
- Add content to pre-formatted slides
- Colors and fonts automatically applied
- No manual formatting needed

### Option 2: Manual Setup (If Theme Not Available)

**Step 1: Open Blank Presentation**
```
File > New > Blank Presentation
```

**Step 2: Set Up Slide Master**
```
View > Slide Master > Edit Master
```

**Step 3: Add Color Scheme**
```
Design > Variants > Colors > Customize Colors
- Add theme colors matching brand palette
- Save as "Executive Forge [Option]"
```

**Step 4: Add Fonts**
```
Design > Variants > Fonts > Customize Fonts
- Set Heading font
- Set Body font
- Save as "Executive Forge [Option]"
```

**Step 5: Create Master Slide Layouts**
```
For each required layout (Title, Content, Two-Column, Three-Column):
  - Duplicate blank slide master
  - Add text boxes and formatting
  - Set font styles and sizes
  - Apply colors
  - Save
```

**Step 6: Close Master View**
```
Slide Master > Close Master View
```

**Step 7: Apply to Slides**
```
Select slide > Design > [Your Custom Theme]
```

### Option 3: Use Google Slides Alternative

**Advantage:** Free, cloud-based, team collaboration

**Implementation:**
1. Create Google Slides presentation
2. Customize theme (File > Theme colors/fonts)
3. Create slide layouts manually
4. Share template as "Master" presentation
5. Team duplicates and customizes per project

### Checklist Before Publishing

- [ ] All slides use brand colors (hex verified)
- [ ] Typography matches brand specifications
- [ ] Logo placed correctly (size, position)
- [ ] No default PowerPoint graphics or colors
- [ ] Charts/graphs use brand color palette
- [ ] Slide numbers and footers present
- [ ] Presenter notes added where applicable
- [ ] Spellcheck completed

## 10. TROUBLESHOOTING & FAQs

### "Charts aren't showing brand colors"
- **Solution:** Right-click chart > Format Data Series > Fill > Solid Fill > Choose color
- Repeat for each data series
- Save chart as favorite for future use

### "Fonts aren't available on team computers"
- **Solution:** Embed fonts in presentation file
- **File > Options > Save > Embed fonts in the file**
- WARNING: Increases file size by ~1-2MB

### "Theme colors not applying to all slides"
- **Solution:** Delete slide and recreate using correct master layout
- Slides > New Slide > Layout > [Correct Layout]

### "Logo appears blurry when enlarged"
- **Solution:** Use vector logo (EPS, SVG) instead of PNG
- If only PNG available, insert at actual display size (don't resize large)

### "Can't find Slide Master on Mac"
- **Solution:** View > Master > Edit Master
- Same steps as Windows version
