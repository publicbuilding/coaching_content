## Typography

### Primary Font (Headlines & Titles)
- **Font Family:** Georgia, Garamond, serif
- **Weight:** Bold (700) / Regular (400)
- **Use:** H1-H3 headlines, brand name, major section titles
- **Size Hierarchy:**
  - H1: 48px (desktop), 32px (mobile)
  - H2: 36px (desktop), 24px (mobile)
  - H3: 24px (desktop), 18px (mobile)
  - H4: 18px

### Secondary Font (Body Text & UI)
- **Font Family:** "Helvetica Neue", Arial, sans-serif
- **Weight:** Regular (400), Medium (500), Bold (700)
- **Use:** Body paragraphs, labels, UI elements, navigation
- **Sizes:**
  - Body: 16px (desktop), 14px (mobile)
  - Small: 12px
  - Label: 13px medium

### Accent Font (Quotes & Callouts)
- **Font Family:** Georgia, serif
- **Style:** Italic
- **Weight:** Regular (400)
- **Use:** Testimonials, pull quotes, featured insights

## Logo Concept

### Wordmark Style (Primary)
```
┌─────────────────────────────────────┐
│                                     │
│  EXECUTIVE FORGE                    │
│  [Sophisticated double-line design] │
│  Deep red text with gold underline  │
│  Secondary line: "Building Legacy"  │
│                                     │
└─────────────────────────────────────┘
```

**Description:** 
- All-caps sans-serif wordmark in Deep Red (#8B2E2E)
- Geometric, sharp angles—conveys precision & strength
- Gold horizontal accent line beneath brand name
- Optional tagline: "Building Legacy" in 60% opacity gray
- Minimum size: 120px width
- Clear space (all sides): 1x logo height

### Icon Mark (Secondary)
```
    ╔═══════════╗
    ║     ◆     ║  Deep Red diamond (strength)
    ║   ▲ ▼ ▲   ║  Gold triangles (growth/stability)
    ║ ◄ ■ ► ■ ◄ ║  Black squares (foundation)
    ║   ▼ ▲ ▼   ║
    ╚═══════════╝
```

**Description:**
- Geometric, interlocking shape
- Deep red diamond center represents core strength
- Gold accents suggest premium positioning
- Can be used as favicon, avatar, seal
- Dimensions: Square 1:1 ratio

## Design Principles

1. **Premium First:** Every visual choice communicates exclusivity & expertise
2. **Timeless Elegance:** Avoid trends; use classic proportions & symmetry
3. **Sophisticated Restraint:** Less is more—white space is luxury
4. **Heritage & Authority:** Serif fonts + deep colors = trust & legacy
5. **Gold Detailing:** Used sparingly for high-impact moments

## Color Applications

### Primary Background
- Deep Red: Premium headers, hero sections, call-to-action buttons
- Usage: 15-20% of design space
- Paired with: White text, gold accents

### Secondary Background
- Off-White: Main content areas, cards, forms
- Usage: Primary background color
- Paired with: Dark text, subtle borders

### Accent Applications
- Gold: Borders, icons, badge highlights, underlines
- Usage: 5-10% of design
- Creates sophisticated emphasis without loudness

### Text Hierarchy
- Headlines (H1-H2): Deep Red or Black
- Body Text: Charcoal Gray on Off-White
- Links: Deep Red with gold underline on hover
- Secondary Info: Medium Gray

## Imagery Style

- **Photography:** Corporate, professional, high-quality
- **Color Treatment:** Subtle deep red or gold color overlay (10-20% opacity)
- **People:** Professional attire, confident expressions, diverse representation
- **Settings:** Executive offices, power lunches, boardrooms, innovation spaces
- **Tone:** Aspirational, accomplished, trustworthy

## Accessibility Compliance

- Deep Red + Off-White: WCAG AA compliant (contrast ratio 7.2:1)
- Black + Off-White: WCAG AAA compliant (contrast ratio 18:1)
- Gold + White: WCAG AA compliant (contrast ratio 6.8:1)
- All text meets minimum 16px on mobile, 14px desktop
