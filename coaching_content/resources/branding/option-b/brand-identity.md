## Typography

### Primary Font (Headlines)
- **Font Family:** "Inter", "Montserrat", sans-serif (modern, geometric)
- **Weight:** Bold (700), SemiBold (600)
- **Use:** Headlines, section titles, key messages
- **Size Hierarchy:**
  - H1: 52px (desktop), 36px (mobile)
  - H2: 40px (desktop), 28px (mobile)
  - H3: 28px (desktop), 20px (mobile)
  - H4: 20px

### Secondary Font (Body & Content)
- **Font Family:** "Open Sans", "Roboto", sans-serif (clean, readable)
- **Weight:** Regular (400), Medium (500), SemiBold (600)
- **Use:** Body text, descriptions, UI labels
- **Sizes:**
  - Body: 16px (desktop), 14px (mobile)
  - Small: 13px
  - Label: 12px medium

### Accent Font (Callouts & Data)
- **Font Family:** "IBM Plex Mono", monospace
- **Use:** Code snippets, data points, technical callouts
- **Weight:** Regular (400)
- **Size:** 13px

## Logo Concept

### Dynamic Wordmark (Primary)
```
┌─────────────────────────────────────┐
│                                     │
│  ► EXECUTIVE FORGE                  │
│    [Bold, modern sans-serif]        │
│    Red arrow + charcoal text        │
│    Clean, forward-thinking          │
│                                     │
└─────────────────────────────────────┘
```

**Description:**
- Bold sans-serif wordmark in Charcoal (#2A2A2A)
- Red right-pointing arrow prefix (#E63946)
- Arrow suggests forward momentum, innovation, growth
- Modern geometric construction
- Minimum size: 100px width
- Clear space: 0.5x logo height

### Geometric Mark (Secondary)
```
  ╔════╗
  ║ ╱╲ ║  Red ascending lines (growth)
  ║╱  ╲║  Charcoal frame (structure)
  ║╲  ╱║  Gold accent (premium)
  ║ ╲╱ ║
  ╚════╝
```

**Description:**
- Ascending triangle/mountain shape
- Red center gradient suggesting growth & energy
- Charcoal border for definition
- Gold accent line on right side
- Can be animated slightly (subtle rotation in digital)
- Dimensions: Square 1:1

## Design Principles

1. **Forward Motion:** Dynamic angles, upward movement, positive energy
2. **Clarity Through Contrast:** Bold colors against clean backgrounds
3. **Digital Native:** Works seamlessly across all screen sizes
4. **Modern Confidence:** Sans-serif, geometric, decisive
5. **Accessible Boldness:** High contrast, clear hierarchy, readable at all sizes

## Color Applications

### Primary Background
- Charcoal: Dark sections, inverse layouts, emphasis zones
- Usage: 20-25% of design space
- Paired with: Cream or white text, gold accents

### Secondary Background
- Cream: Primary content, cards, spacious layouts
- Usage: 60-65% of design
- Paired with: Charcoal text, red highlights

### Accent Usage
- Vibrant Red: CTAs, hover states, highlighted data, badges
- Navy: Secondary actions, depth layers, alternative CTAs
- Gold: Borders, premium sections, testimonial highlights
- Usage: 15-20% combined

### Text Hierarchy
- Headlines (H1-H2): Charcoal with red accent word
- Body Text: Charcoal on cream
- Links: Red with underline on hover
- Labels: Medium gray

## Imagery Style

- **Photography:** Modern, dynamic, real-world action shots
- **Color Treatment:** Vibrant red overlay (15-25% opacity) for consistency
- **People:** Diverse, energetic, modern professionals
- **Settings:** Tech offices, collaborative spaces, innovation hubs, startup environments
- **Tone:** Progressive, confident, forward-thinking, inclusive
- **Graphics:** Bold geometric shapes, data visualizations, charts

## Accent Applications

- **Call-to-Action Buttons:** Vibrant red background, white text, rounded corners (8px)
- **Links:** Red text with gold underline, hover → darker red
- **Borders & Dividers:** Charcoal 1px, or red accent 2px for emphasis
- **Icons:** Red, charcoal, or gold—bold, geometric style
- **Badges & Tags:** Red background with cream text, or charcoal border

## Accessibility Compliance

- Red + Cream: WCAG AA compliant (contrast ratio 6.9:1)
- Charcoal + Cream: WCAG AAA compliant (contrast ratio 17.5:1)
- Navy + Cream: WCAG AA compliant (contrast ratio 8.2:1)
- All elements tested for color-blindness compatibility
