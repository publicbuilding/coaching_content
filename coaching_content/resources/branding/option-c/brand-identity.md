## Typography

### Primary Font (Headlines & Titles)
- **Font Family:** "Helvetica Neue", "Arial", sans-serif (clean, universal)
- **Weight:** Bold (700)
- **Use:** Headlines, key messages
- **Size Hierarchy:**
  - H1: 48px (desktop), 32px (mobile)
  - H2: 32px (desktop), 22px (mobile)
  - H3: 24px (desktop), 18px (mobile)
  - H4: 18px

### Secondary Font (Body Text)
- **Font Family:** "Segoe UI", "Open Sans", sans-serif
- **Weight:** Regular (400)
- **Use:** Body paragraphs, descriptions, all continuous text
- **Sizes:**
  - Body: 16px (desktop), 15px (mobile)
  - Small: 13px
  - Label: 12px

### Special Font (Emphasis)
- **Font Family:** Same as primary
- **Weight:** Regular (400), Bold (700)
- **Use:** Pull quotes, emphasis, data callouts
- **Style:** Minimal styling—let whitespace speak

## Logo Concept

### Minimalist Wordmark (Primary)
```
┌─────────────────────────────────────┐
│                                     │
│ EXECUTIVE FORGE                     │
│ [Clean, geometric sans-serif]       │
│ Dark gray text with red accent bar  │
│ Simplicity at scale                 │
│                                     │

```

**Description:**
- All-caps sans-serif wordmark in Dark Gray (#2C3E50)
- Single thin red horizontal line positioned under 50% of text width
- Suggests foundation, precision, balance
- Extremely legible at any size
- Minimum size: 80px width
- Clear space: 0.75x logo height
- Monochrome version (gray only) works for restricted applications

### Symbol Mark (Secondary - Optional)
```
  ┌────┐
  │ ─── │  Red horizontal line (foundation)
  │ ──  │  Dark gray lines (structure)
  │  ── │  Minimalist stacked approach
  └────┘
```

**Description:**
- Three horizontal lines with subtle offset
- Red top line (primary focus)
- Gray lines (stability)
- Represents minimalist, organized thinking
- Square 1:1 ratio
- Scalable to 16px favicon

## Design Principles

1. **Essential Only:** Every element must have purpose
2. **Whitespace is Content:** Empty space creates focus and clarity
3. **Typographic Emphasis:** Use scale & weight, not color
4. **One Accent:** Red used very sparingly, with intent
5. **Universal Clarity:** Works across all contexts, devices, sizes

## Color Applications

### Neutral-First Approach
- **White:** Primary background (85-90% of space)
- **Dark Gray:** Text, structure, hierarchy
- **Light Gray:** Secondary text, borders, dividers

### Red Accent Strategy
- **Sparingly Used:** Only on CTAs, critical alerts, primary navigation highlights
- **Usage:** 2-5% of total design
- **Impact:** High contrast, draws immediate attention
- **Applications:** Submit buttons, current page indicators, key metrics

### Gold Accent (Rare)
- **Reserved for:** Premium sections, special badges, footnotes
- **Usage:** <2% of design
- **Purpose:** Subtle elevation without visual clutter

### Text Hierarchy
- Headline (H1): Dark Gray, 48px
- Subheading (H2): Dark Gray, 32px
- Body: Dark Gray, 16px
- Secondary: Light Gray, 14px
- Links: Red with subtle underline; gray in footer

## Imagery Style

- **Photography:** Minimal, clean, composed shots
- **Color Treatment:** Black & white with optional red accent (single element)
- **People:** Professional, candid, minimal props
- **Settings:** Clean workspaces, minimalist environments, nature, simplicity
- **Tone:** Focused, intentional, no-nonsense, clarity-driven
- **Graphics:** Geometric shapes, line drawings, icon-style illustrations

## Layout Principles

### Grid
- Desktop: 12-column grid, 20px gutters
- Tablet: 8-column grid, 16px gutters
- Mobile: 4-column grid, 12px gutters

### Whitespace
- Margins: 40px (desktop), 20px (tablet), 16px (mobile)
- Section gaps: 60px (desktop), 40px (mobile)
- Element spacing: Multiples of 8px (8, 16, 24, 32, 40)

### Hierarchy Using Only Type & Space
- Large headline + generous whitespace below
- Body text set to 60-70 character line length for readability
- List items: use line-height 1.6x for clarity
- Callouts: increase whitespace, not size

## Accent Applications

- **Primary Button:** Dark Gray background, white text, minimal border, 4px radius
- **Secondary Button:** White background, dark gray text, 1px gray border
- **CTA Button:** Red background, white text, 4px radius (ONLY for critical actions)
- **Links:** Red text in body, gray in footer
- **Form Fields:** Light gray border, white background, focus = dark gray border
- **Icons:** Dark gray, light gray for secondary, red for alerts only

## Accessibility Compliance

- Dark Gray + White: WCAG AAA compliant (contrast ratio 12.6:1)
- Red + White: WCAG AA compliant (contrast ratio 6.2:1) — may need verification
- Light Gray + White: WCAG AA compliant (contrast ratio 4.5:1)
- All text set to maximum 70-75 characters per line for readability

## Responsive Considerations

- Remove non-essential visual elements on mobile
- Rely on typography hierarchy, not color
- Maintain whitespace proportions across all sizes
- Icons scale to maintain visual weight
