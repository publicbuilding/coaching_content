## 🔧 Customization

### Replace Images
All CSV files reference placeholder URLs (`https://example.com/img/...`).

**Before importing:**
1. Create actual images for each post
2. Upload to image hosting (Imgix, Cloudinary, etc.)
3. Get permanent URLs
4. Replace in CSV before importing

### Modify Times
If optimal times don't match your audience:
1. Open CSV in spreadsheet
2. Edit `scheduled_time` column
3. Change times (keep format: `YYYY-MM-DD HH:MM:SS`)
4. Save and re-import

### Adapt Copy
Posts are templates. Customize:
- Brand voice (more formal, more casual, etc.)
- Company name (replace "Executive Forge")
- Links (Gumroad → your store)
- Hashtags (add/remove based on your niche)

**Important:** Don't change meaning; test with audience first.

## 📞 Support & Troubleshooting

### Import Issues
- **CSV not recognized?** → See BUFFER_IMPORT_GUIDE.md or LATER_IMPORT_GUIDE.md (Troubleshooting section)
- **Images not loading?** → Replace `https://example.com/img/...` with real URLs
- **Timezone wrong?** → Check platform settings (must be UTC)
- **Posts not scheduled?** → Verify account permissions granted

### Engagement Issues
- **Low engagement?** → Check SOCIAL_CALENDAR.md (Week 2-4 strategy)
- **Wrong audience?** → Review hashtags; consider platform-specific variants
- **Not many clicks?** → Verify links work; test different CTAs
- **Questions/comments?** → Respond quickly; build community

### Technical Help
- **Buffer support:** https://support.buffer.com
- **Later support:** https://www.later.com/support
- **CSV format help:** Check guides in this folder

## 💡 Pro Tips

### Monitor from Day 1
- Watch first week's posts closely
- Note which angles/topics resonate
- Identify top 10% of content
- Plan next batch around winners

### Engage Actively
- Respond to every comment (first 48h)
- Ask follow-up questions
- Build relationships with followers
- Create community, not just broadcast

### Optimize Weekly
- Export analytics every Friday
- Identify top 3 posts
- Note common patterns
- Plan next week's content around winners

### Repurpose Winners
- High engagement? Requeue 3 weeks later
- With slightly different copy/image
- Test if it performs again
- Evergreen content = free reach

### Build Email List
- Mention newsletter in every post
- Link to signup page
- Offer exclusive content to subscribers
- This compound effect is how you scale
