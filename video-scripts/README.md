## 🎙️ Delivery Tips

1. **Pacing:** Slow down on key points. Speed up on examples.
2. **Energy:** Hook is high energy. Middle sections conversational. CTA confident but warm.
3. **Pauses:** Pause after key statements (2-3 seconds). Let them land.
4. **Eye contact:** Direct to camera on hooks, CTAs, and key insights.
5. **Authenticity:** These aren't sales pitches. These are lessons learned. Sound like you're sharing hard-won wisdom.
